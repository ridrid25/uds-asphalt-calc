# «Первая победа» за 5 минут

Первый пункт роадмапа CFO-агента, реализованный кодом: команда `/first_win` и кнопка под сообщением.

**Что происходит у клиента.** Он подключил свою таблицу. Бот тут же предлагает: «Данные на месте. Хотите, покажу три вещи, которые я в них увидел?» — с кнопкой **✨ Показать первую победу**. Нажимает — и через несколько секунд получает:

```
Сергей, я посмотрел ваши данные. Вот что нашёл за 30 секунд:

✅ Выручка выросла на 3% к прошлому периоду — до 1 800 000 ₽.

📊 Из каждых 100 ₽ выручки в бизнесе остаётся 10 ₽ — это ваша маржа за последние 30 дней.

⚠️ Просроченная дебиторка — 610 000 ₽. Это 34% от выручки за период.
   Эти деньги уже заработаны, но лежат не у вас.

👉 Одно действие на сегодня: Выберите самого крупного должника и позвоните ему сегодня.
```

Порядок фиксирован: сначала хорошее, потом наблюдение, потом одна зона роста и ровно одно действие.

## Подключить к боту

Три строки в вашем `main.py`:

```python
from first_win import register, offer_first_win

register(application, load_snapshot)   # даёт команду /first_win и кнопку
```

`load_snapshot` — ваша функция: по `chat_id` вернуть данные клиента или `None`, если таблица ещё не подключена. Может быть обычной или `async`.

```python
from first_win import BusinessSnapshot

def load_snapshot(chat_id: int) -> BusinessSnapshot | None:
    row = db.get_client(chat_id)          # ваше хранилище
    if not row:
        return None
    return BusinessSnapshot(
        revenue=row.revenue,
        expenses=row.expenses,
        cash=row.cash,
        receivables=row.receivables,
        overdue_receivables=row.overdue,
        prev_revenue=row.prev_revenue,
        owner_name=row.owner_name,
    )
```

И одна строка в конце вашего хендлера подключения таблицы — чтобы кнопка появилась в тот момент, когда клиенту интересно:

```python
await offer_first_win(chat_id, context)
```

Обязательны только `revenue`, `expenses` и `cash`. Чего нет — не передавайте: анализ подстроится и не станет выдумывать недостающее.

## Ключ к Claude

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

Без ключа фича не ломается — бот считает три факта арифметикой из тех же цифр. Клиент в любом случае получает ответ.

### Три решения, которые стоит знать

**Первый факт не может оказаться плохим.** Ответ модели ограничен схемой из четырёх полей — `positive`, `observation`, `risk`, `action_today`. Модель физически не может вернуть их в другом порядке или прислать четыре плохие новости. Это свойство структуры, а не надежда на формулировку промпта.

**Сбой не портит первое впечатление.** Нет ключа, упала сеть, пришёл битый ответ, запрос отклонён — клиент всё равно видит три факта, посчитанных локально. Проверено тестами на все четыре сценария.

**Запрос не блокирует бота.** Обращение к Claude уходит в отдельный поток. Пока считается ответ одному клиенту, остальные продолжают пользоваться ботом.
